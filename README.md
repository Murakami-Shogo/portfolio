# 村上 彰悟 Portfolio

機械学習・深層学習（特に自然言語処理）を専門とする村上彰悟のポートフォリオです。

## 掲載内容

- About
- Research
- Competitions
- Blog
- CV

## 使用技術

- Astro
- TypeScript
- Tailwind CSS

## 起動方法

```bash
npm install
npm run dev
npm run build
```

## 公開URL

https://murakami-shogo-portfolio.vercel.app/
